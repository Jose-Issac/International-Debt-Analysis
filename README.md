# International-Debt-Analysis
Exploratory data analysis and Power BI dashboard analyzing external debt trends across 120+ countries (2000–2024), using World Bank International Debt Statistics (IDS) data.
📌 Overview

This project analyzes country-wise external debt distribution, identifies top and bottom indebted nations, explores key debt indicators (debt-to-GNI, debt service ratios, reserves, short-term debt exposure), and visualizes patterns and trends through an interactive Power BI dashboard.

🎯 Objectives
Analyze country-wise external debt distribution
Identify countries with the highest and lowest debt burdens
Explore key debt indicators and their relationships
Detect trends, patterns, and year-over-year changes (2000–2024)
Perform statistical summaries and cross-country comparisons
Build an interactive Power BI dashboard for exploration
🛠️ Tools & Technologies
Python (pandas, matplotlib, seaborn) — data cleaning, EDA, statistical analysis
Power BI — interactive dashboard, DAX measures, data visualization
Jupyter Notebook — analysis workflow
SQL - Analysis and Report
📊 Key Analyses
Country-wise debt distribution (histogram, summary statistics)
Top 10 / Bottom 10 countries by external debt
Debt breakdown by Income Group and Region
Multi-year debt trend for top indebted countries (2000–2024)
Correlation between key debt indicators (Debt/GNI, Debt Service/Exports, Reserves, Interest payments)
Debt risk flagging (Debt/GNI > 60% threshold)
Debt Burden vs. Repayment Pressure (debt sustainability quadrant)
Year-over-year debt growth rate by country
Debt growth comparison across a multi-year period (2015–2023)
